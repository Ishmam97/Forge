## Problem

## Target user

## Jobs to be done
What is the user trying to accomplish when they reach for this? Use JTBD format:
"When [situation], I want to [motivation], so I can [outcome]."

## Value hypothesis

## Competitive landscape
Existing solutions. For each: what they do well, what they miss.

## Success metrics
The 1-3 numbers we'd watch to know this is working. Each metric should have a baseline (current state) and a target.

## Risks and unknowns
What could kill this? What do we not yet know that we need to know?

## Non-goals
Explicit list of what this is *not*. Anti-scope is as important as scope.
